# Sand Loop - 落沙循环

一个基于元胞自动机的落沙模拟微信小游戏，灵感来自 Voodoo 的 Sand Loop。

## 核心玩法

### 1. **初始状态**
- 画框中有一副完整的像素画（粉色猫咪，约6万+像素）
- 传送带是空的，持续从左到右循环移动
- 下方有颜色选择器（紫色、粉色、黄色、橙色）

### 2. **操作方式**
1. **点击下方颜色桶** → 桶自动飞到传送带的空位上
2. **桶随传送带移动** → 经过画框底部时吸取对应颜色的沙子
3. **沙子被吸走** → 上方沙子因重力塌陷下落
4. **桶装满后** → 自动销毁并移除，释放位置给新桶

### 3. **传送带机制**
- 传送带持续**从左向右**无限循环移动
- 桶和槽位**一起移动**，保持相对位置
- 从右边出去后，自动从左边重新进入
- 装满的桶**自动销毁**，无需手动点击

## 游戏机制详解

### 落沙机制（真实沙子物理）
- 像素画初始填满整个画框
- **优先垂直下落**：保持图案整体结构
- **概率性斜向滑落**：当底部出现空洞时，周围沙子有概率斜向滑入填充
  - 两边都可滑：70%概率选择一边滑下
  - 只有一边可滑：60%概率滑下
  - 添加微小随机延迟，使下落模式更自然
- **模拟沙子流动性**：像液体一样流动填充空洞，但不会完全破坏图案

### 吸沙机制
- 桶只在**画框底部**才会吸沙
- 只吸取**与桶颜色相同**的沙子
- 每列只吸**最底部的一个**（一层一层吸）
- 桶容量：**1500像素**（一幅画约需40+桶才能清空）

### 传送带循环机制
```
屏幕: [                    ]
         ↓ 放置桶
槽位: [🟣]→[💗]→[ ]→[🟡]→[ ]
         ↓ 向右移动
循环: 当最右槽位移出屏幕 → 从左边重新进入
```

| 点击 ⚙ | 暂停/继续游戏 |
| 点击 ↺ | 重新开始 |
| 点击颜色桶 | 生成对应颜色的桶到传送带 |
| 点击道具 | 使用道具效果 |

## 技术实现

- **元胞自动机**：核心落沙算法，模拟沙子重力塌陷
- **Canvas 渲染**：原生 Canvas API 实现高性能渲染
- **传送带循环**：偏移量累加 + 模运算实现无限循环
- **微信小游戏 API**：触摸事件、Canvas 渲染
